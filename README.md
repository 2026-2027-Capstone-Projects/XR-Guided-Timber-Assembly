# XR-Guided-Timber-Assembly

Unity Editor Version: 6000.3.26f1

## Instructions
To open and run the program in the Unity Editor, open the project, then in the project window, navigate to Assets/Scenes and select "MC1Scene"(make sure to select the scene file, not the folder of the same name)

Then after opening the file, click the play button at the top of the editor to test to program.
